## ✨ Características do Projeto

O site da **Ativa Contabilidade** foi projetado para transmitir confiança, profissionalismo e inovação. As principais seções e recursos incluem:

*   **Design Premium & Responsivo:** Interface otimizada para dispositivos móveis, tablets e computadores.
*   **Animações Fluídas (Motion):** Transições suaves de entrada e micro-interações que melhoram a experiência de navegação.
*   **Foco em Resultados:** Apresentação clara de estatísticas de crescimento, soluções personalizadas e depoimentos.
*   **Seções Dinâmicas:**
    *   **Marketing Hero:** Banner inicial de alto impacto com chamadas para ação claras.
    *   **ProcessStats:** Exibição dinâmica de métricas e indicadores de sucesso.
    *   **ProgressSection:** Visualização interativa da jornada e progresso da parceria com o cliente.
    *   **Soluções Corporativas:** Catálogo de serviços especializados para empresas de todos os portes.

## 🛠️ Stack Tecnológica

O projeto foi desenvolvido utilizando as tecnologias mais modernas do ecossistema web para garantir performance, escalabilidade e manutenibilidade:

*   **[React 19](https://react.dev/):** Biblioteca para construção de interfaces reativas e modulares.
*   **[Vite](https://vite.dev/):** Ferramenta de build extremamente rápida para desenvolvimento ágil.
*   **[Tailwind CSS v4](https://tailwindcss.com/):** Framework CSS utilitário para estilização robusta e responsiva de última geração.
*   **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para maior segurança e prevenção de bugs em tempo de desenvolvimento.
*   **[Motion](https://motion.dev/):** Biblioteca moderna de animações para React.
*   **[Lucide React](https://lucide.dev/):** Conjunto de ícones vetoriais limpos e consistentes.

## 🚀 Como Rodar Localmente

Siga os passos abaixo para clonar o repositório e executar o projeto em sua máquina de desenvolvimento.

### Pré-requisitos
*   [Node.js](https://nodejs.org/) (Recomendado: LTS)
*   [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/seu-usuario/ativa-contabilidade.git
    cd ativa-contabilidade
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    ```

3.  **Configuração de Variáveis de Ambiente:**
    Crie um arquivo `.env` na raiz do projeto (se necessário) utilizando o `.env.example` como base:
    ```bash
    cp .env.example .env
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

5.  **Acesse no navegador:**
    Abra [http://localhost:3000](http://localhost:3000) para ver o site em execução.

## 📦 Scripts Disponíveis

No diretório do projeto, você pode executar:

*   `npm run dev`: Inicia o servidor de desenvolvimento local.
*   `npm run build`: Compila a aplicação para produção na pasta `dist/`.
*   `npm run preview`: Executa localmente o build de produção para validação.
*   `npm run lint`: Executa a checagem de tipos do TypeScript (`tsc --noEmit`).
*   `npm run clean`: Limpa as pastas temporárias de build.
